# Website UI kit

The redesigned tomkeefe.ai homepage, built entirely on the system: sticky ruled nav, flush-left display hero, 4-up stat row, numbered principles with Draft tags, project card grid with status vocabulary, about + skills grid, red poster contact close. Light/dark via the nav toggle (persists to localStorage key `tk-theme`).

Content is the live site's copy, lightly professionalized; stats are fake placeholders and project descriptions keep their [PLACEHOLDER] markers by design.
