One-line: the section opener — use it instead of a mono "01 / SECTION" label, which was deliberately removed from this brand.

```jsx
<SectionHeading
  title="Things I built instead of waiting for a vendor."
  subhead="Two are running today. Read either one for the problem, the build and what it cost."
/>
```

Titles are sentences with a full stop, not labels. On the contact band pass `size="contact"`.
