Small tinted label for statuses and categories.

```jsx
<Tag variant="live">Live</Tag>
<Tag variant="draft">Draft</Tag>
<Tag variant="neutral">Internal</Tag>
```

`live` = accent tint + filled square; `draft` = neutral tint + outlined square (use for Draft / In development / TBC); `accent`, `neutral`, `outline` for plain labels. Uppercase not required; sentence case.
