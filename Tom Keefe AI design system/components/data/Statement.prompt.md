One-line: a numbered opinion, set large — the claim carries the section.

```jsx
<Statement index="03" annotation="Inventory exists because I kept packing the same bag wrong.">
  If your team does it manually every week, that's not a process. It's a hostage situation.
</Statement>
```

`annotation` is the receipt — the line that ties the claim to a project. It's set clearly subordinate (`--size-row`, `--muted`) so the claim still lands first. Two sentences is fine; it may run longer than the claim itself.

**Only some statements carry one.** Nothing is reserved when it's absent, so the unannotated ones don't read as incomplete. Don't add a filler annotation for symmetry.

`index` is optional. Numbering implies sequence or ranking — if the statements are unranked, drop it and put the count in the section heading (`Six opinions`) instead of numbering things that have no order.
