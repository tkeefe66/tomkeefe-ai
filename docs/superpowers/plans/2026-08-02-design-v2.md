# Design v2 (Enterprise-Document / Navy) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Replace the v1 design (Archivo, red accent) of tomkeefe.ai with the v2 "enterprise-document" design from `website design v2/` — navy masthead + contact band bookending a white document body, Onest + IBM Plex Mono, sticky navy nav with Projects dropdown, and two new project detail pages.

**Architecture:** Content stays in `content/*.ts` (rewritten to the v2 information architecture); design tokens and component recipes live in `app/globals.css` (`:root` + `[data-theme="dark"]`, Tailwind v4 `@layer components`); React components in `components/` combine those classes with Tailwind layout utilities. Project detail pages are two explicit static routes sharing one `ProjectPage` component (no dynamic `[slug]` — avoids Next 16 async-params entirely).

**Tech Stack:** Next.js 16.2.10 (App Router), React 19, TypeScript, Tailwind v4 (`@tailwindcss/postcss`), `next/font/google`, vitest.

## Global Constraints

- **Read `node_modules/next/dist/docs/` guidance first** — this Next.js has breaking changes vs. training data (AGENTS.md). The orchestrator supplies a docs digest with each task; follow it.
- Spec source of truth: `website design v2/README.md` + `website design v2/Tom Keefe.dc.html`. Copy is verbatim from those files — do not rewrite copy.
- Fonts: **Onest** (400/500/600/700) for UI+headings, **IBM Plex Mono** (400/500) for labels/metadata — via `next/font/google` only, never a CDN `<link>`.
- Body default: `letter-spacing: -0.011em`, antialiased. Mono text is always UPPERCASE.
- Accent = **Navy**. Light: `--acc #1D3A63 --accHover #152C4C --tint #E8EDF4 --tintEdge #D0DAE8 --accDeep #152C4B --accSoft #A6BCD8 --accInk #FFFFFF`. Dark: `--acc #7FA6D9 --accHover #95B8E4 --tint #161C26 --tintEdge #26313F --accDeep #1B3050 --accSoft #9DBBDD --accInk #101113`.
- Neutrals light: `--bg #FFFFFF --ink #0B0D10 --body #3B424C --muted #6B7280 --faint #9AA1AC --hair #E4E6EA --sunk #F7F8F9`. Dark: `--bg #101113 --ink #F0F0F0 --body #C4C4C8 --muted #8B8B8E --faint #5F5F63 --hair #26272B --sunk #17181A`.
- **Nothing hard-codes a neutral or accent hex in components** — CSS custom properties only. (Exception: the `rgba(255,255,255,…)` values on navy bands and `#FFFFFF` type on navy, which are white in both themes per spec.)
- Colour is structural: exactly two full-bleed `--accDeep` fields (masthead+tech strip, contact band) plus `--acc` type on labels listed in the spec. No tinted boxes, no gradients except figure-plate fades, no new colour surfaces.
- Radius: 3px buttons/nav pills, 4px dropdown panel, 0 figure plates. No shadows except the nav dropdown (`0 12px 28px rgba(0,0,0,0.14)`).
- Container: `max-width: 1180px; margin: 0 auto; padding: 0 44px` (mobile: 20px side padding below 640px).
- Theme: `data-theme="dark"` on `<html>`, persisted as `tk-theme`, respects `prefers-color-scheme` when unset. 220ms background/color transition.
- Honour `prefers-reduced-motion` (marquee stops and wraps; smooth scroll off).
- Sections use `scroll-margin-top: 64px` (nav is 56px sticky).
- Run `npm run lint` and `npm run test` before every commit; `npm run build` in the final task.
- **Next 16 facts (from the bundled docs — trust these over training data):** `params`/`searchParams` are async-only (we avoid them by using explicit routes); Turbopack is the default builder; `next/image` default `images.qualities` is `[75]` — do not pass a `quality` prop; multi-word Google fonts import with underscores (`IBM_Plex_Mono`) and non-variable fonts REQUIRE a `weight` array; Tailwind v4 font wiring is `@theme inline` in CSS, never `tailwind.config.js`; a global `scroll-behavior: smooth` needs `data-scroll-behavior="smooth"` on `<html>` for Next to manage scroll on route transitions; `metadata` exports only from server components.
- Before every commit output exactly one line: `Skill candidate: <name> - <desc>` or `Skill candidate: none.`

export type LedgerRow = { label: string; value: string };
export type SiteLink = { label: "EMAIL" | "LINKEDIN" | "GITHUB"; href: string };

export type SiteContent = {
  name: string;
  domain: string;
  /** One-line description used in <title>/meta. */
  tagline: string;
  mastheadVariant: "ledger" | "column";
  masthead: {
    lead: string;
    ledger: LedgerRow[];
    column: { headline: string; support: string; facts: string[] };
  };
  techStrip: string[];
  links: SiteLink[];
  contactHeadline: string;
  footer: { left: string; right: string };
  notFound: { headline: string; line: string; cta: string };
};

export type RangeContent = {
  headline: string;
  subhead: string;
  paragraph: string;
  altitudes: { label: string; text: string }[];
};

export type Principle = { text: string };

export type ProjectRow = {
  name: string;
  description: string;
  /** Present = row links to /projects/<slug> and shows READ →. */
  slug?: string;
  /** Inert rows only. */
  status?: "IN PROGRESS" | "LIVE";
};

export type ProjectSection = {
  heading: string;
  body: string;
  /** Renders in --faint: outcome placeholder awaiting a real metric. */
  pending?: boolean;
};

export type ProjectFigure = {
  src: string;
  alt: string;
  caption: string;
  /** Fixed plate height in px. */
  height: number;
  /** true = image at 190% width (crop pattern); false = 100% width. */
  wide: boolean;
  /** Natural image dimensions for next/image. */
  width: number;
  naturalHeight: number;
};

export type ProjectDetail = {
  slug: string;
  number: string;
  title: string;
  menuSubtitle: string;
  premise: string;
  sections: ProjectSection[];
  facts: LedgerRow[];
  figures: ProjectFigure[];
  /** Inventory only: paragraph beside FIG. 02. */
  digestNote?: string;
  next: { slug: string; label: string };
};

export default function Nav() {
  const [menuOpen, setMenuOpen] = useState(false);
  const close = () => setMenuOpen(false);

  // Document-level so Escape also closes a hover-opened menu with no
  // focus inside the wrapper (wrapper onKeyDown never fires in that case).
  useEffect(() => {
    if (!menuOpen) return;
    const onKey = (e: KeyboardEvent) => {
      if (e.key === "Escape") setMenuOpen(false);
    };
    document.addEventListener("keydown", onKey);
    return () => document.removeEventListener("keydown", onKey);
  }, [menuOpen]);

  return (
    <nav className="band sticky top-0 z-40" aria-label="Main">
      <div className="container-page flex h-14 items-center justify-between gap-6">

          <Link href="/#range" className="nav-link max-sm:hidden">
            Overview
          </Link>
          <div
            className="relative"
            onMouseEnter={() => setMenuOpen(true)}
            onMouseLeave={close}
            onBlur={(e) => {
              if (!e.currentTarget.contains(e.relatedTarget)) close();
            }}
            onKeyDown={(e) => {
              if (e.key === "Escape") close();
            }}

              href="/#projects"
              className="nav-link"
              aria-expanded={menuOpen}
              aria-haspopup="true"

                  background: "var(--bg)",
                  border: "1px solid var(--hair)",
                  boxShadow: "0 12px 28px rgba(0,0,0,0.14)",
